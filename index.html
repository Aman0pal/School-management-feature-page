2. Role-Based Access Control (RBAC) & Authentication

Granular permission sets securing every interaction. Clear segregation between governance, administration, and learning workflows.

Complete macro-oversight and governance authority across the institutional group.

  • ✓ System Control: Define institution-wide policies, academic sessions, and fiscal years.
  • ✓ Strategic Dashboards: View real-time aggregated cashflows, school rankings, and operational KPIs.
  • ✓ Audit Authorization: Access audit logs, inspect system overrides, and approve high-value procurement.
👨‍🏫

Admin / Teacher

Day-to-day operations and classroom workflow orchestrators with targeted administrative access.

  • ✓ Academic Execution: Mark student attendance, manage daily period logs, and create syllabi.
  • ✓ Assessment Entry: Input assessment grades, publish term results, and assign homework.
  • ✓ Operational Actions: Raise fee reminders, manage inventory issues, and answer guardian queries.

User (Student / Parent)

  • ✓ Academic Tracking: Review class schedules, download assignments, and view terminal marksheets.
  • ✓ Financial Self-Service: Pay term fees securely online, view dues ledger, and download tax receipts.
  • ✓ Interaction: Apply for leaves, track school transport in real time, and message subject teachers.
